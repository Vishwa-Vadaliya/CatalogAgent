# Requirement restatement (A0)

Post this before starting work, and wait for the user to confirm or correct it.

```
Requirement 1: <what is being asked, in one line>
Requirement 2: ...
Requirement 3: ...

Open question: <anything the ask leaves ambiguous — ask it here, don't assume a default>
```

Rules of thumb:

- Short points, limited to what was **actually** asked. Not a plan, not a summary written afterwards.
- Anything you inferred rather than read goes in "Open question", not in the numbered list.
- Skip the whole thing for a trivial one-line ask with nothing to disambiguate.
